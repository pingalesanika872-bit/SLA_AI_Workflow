# AI Workflow Project

## About the Project

This project is a simple AI workflow created as part of the SLA component. The project demonstrates how an AI-based program can interact with the user and provide responses based on the user's input.

## Features

* Greets the user
* Takes the user's name
* Asks how it can help
* Responds to basic commands
* Provides a simple interactive experience

## Technologies Used

* Python
* Git
* GitHub
* Visual Studio Code

## How to Run

1. Open the project in Visual Studio Code.
2. Open the Python file.
3. Run the program using Python.
4. Follow the instructions displayed on the screen.
